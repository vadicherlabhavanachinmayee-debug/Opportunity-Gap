# Opportunity Gap

**Stop missing opportunities.**

Opportunity Gap is a platform designed to help people discover relevant opportunities and avoid missing them through personalized discovery and eligibility tracking.

## Features

- **User Authentication** – Register and log in securely.
- **Opportunity Discovery** – Explore available opportunities.
- **Eligibility Analyzer** – Check whether opportunities match your eligibility.
- **Saved Opportunities** – Save opportunities for later.
- **Notifications** – Stay informed about relevant updates.
- **User Profile** – Manage your profile.

## Tech Stack

**Frontend**
- React
- TypeScript
- Vite
- CSS

**Backend**
- Java
- Spring Boot
